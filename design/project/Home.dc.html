Move a file between devices with just light.

Strip turns a file into a printable data strip or an animated code on your screen. A phone camera reads it back.

How it works

  1. 01

    Pick a file

    Strip splits it into packets and adds repair packets, so a missed frame is not fatal.

  2. 02

    Show the code

    Print the strip on paper, or play the animated code on screen.

  3. 03

    Scan it

    A phone camera reads the packets. The file is rebuilt and checked against its SHA-256.
