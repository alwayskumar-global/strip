06

Conventions

CSP

No style="" anywhere. State is a class (.ring--bad, .stage__code--l), a native attribute (value, checked) or an SVG presentation attribute. No inline script handlers.

Responsive

Roots are containers (.page, .rx, .err); layout switches at 760 px container width, not viewport. The same markup renders desktop and mobile.

Print

.paper is built in container units (cqw) so A4 and Letter scale with no per-size CSS. Print resets every colour to #000 on #FFF; accents never print. Named pages (@page a4, @page letter) switch the sheet.

07

Revision 2 additions

Photo input · .picker .capture .photos

A file input styled as a button, one photo per pick, so pages are added one at a time. Each added photo is a .photo row: thumbnail, “n symbols found”, remove button. The tag in the list header carries the running count.

Step controls · .stepctl .fs

Previous and Next are enabled when paused or in step mode. Full screen switches to .fs: white field, symbol at maximum size, controls only in the corner and on the bottom edge, never over the symbol.

Photosensitivity notice · .callout--warn

Always visible above the stage on Send › Screen. Step mode is the default when the system asks for reduced motion (prefers-reduced-motion).

Paper header · .paper__head

File name, SHA-256 short form, “Page n of N” and a 4-character session id (7F3A) on every page. Registration marks at all four corners.

Symbols · Symbol.dc.html

Placeholder for a version-30 QR symbol: 137 modules plus a 4-module quiet zone is 145 wide, 9 per page in a 3 × 3 grid. The sample file is 111 source packets, 149 symbols, 17 pages. The app draws the real symbols into the same slot.

Errors · ErrorState.dc.html

One component, fourteen kinds, chosen by the kind prop: title, one-sentence explanation, one next action.
