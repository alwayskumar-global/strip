# Product: Strip (working name)

Strip is a modern rebuild of the 1985 Cauzin Softstrip idea, where data strips carried files on paper. It turns any file into either a printable strip or an animated on-screen code sequence. A phone camera reads it back. It is an entry in the hackathon's Resurrection category.

Sender and receiver are both in one PWA. Everything runs client-side.

## Non-goals

- No backend.
- No accounts.
- No network use at runtime.
- No encryption in v1.
- No native apps.
- No cloud services of any kind.
